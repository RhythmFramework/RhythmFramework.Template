# RhythmFramework.Template
Mod template for RhythmFramework

1. Run the command `git clone https://github.com/RhythmFramework/RhythmFramework.Template.git`
2. In the csproj, change line 21 to your location of Rhythm Doctor.
3. Run `dotnet build` in the folder to make sure everything works.

## Having issues?
Create a github issue at the top, and we will try to respond as fast as possible.
